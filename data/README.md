# Dados em preparação

`raw/` receberá cenários autorizados/sintéticos; `processed/`, pares revisados por
split; `manifests/`, proveniência, hashes e contagens. Ainda não há corpus aqui.

As fixtures em `tests/fixtures/` são testes de software, não dados de pesquisa.
Leia o [guia de anotação](../docs/ANNOTATION_GUIDELINES.md) e o
[contrato JSONL](../docs/CONTRACTS.md) antes de criar dados. A licença do futuro
dataset será decidida após verificar os direitos de redistribuição.
